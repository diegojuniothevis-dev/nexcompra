# NexCompra para Android

Aplicativo Android do NexCompra ERP Enterprise 5.3.2.

- Site oficial carregado com conexão HTTPS.
- Login e sessão do Supabase mantidos no WebView.
- Importação de XML, planilhas e outros arquivos pelo seletor Android.
- Downloads direcionados para a pasta Downloads.
- Links externos abertos no aplicativo adequado.
- Compatível com Android 7.0 ou superior.

O APK de produção usa assinatura de teste para permitir instalação direta. Para publicar na Play Store, configure uma chave privada de produção e gere um Android App Bundle (AAB).
